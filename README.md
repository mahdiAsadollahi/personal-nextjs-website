# مهدی اسداللهی — دنیا از یه زاویهٔ دیگه

یه وبلاگ شخصی فارسی (RTL) با پنل مدیریت، ساخته‌شده با Next.js و Tailwind CSS.

## دربارهٔ پروژه

این پروژه یه وبلاگ شخصی و پورتفولیوئه که با تمرکز روی طراحی مینیمال، تایپوگرافی فارسی و تجربهٔ کاربری راست‌به‌چپ ساخته شده. علاوه بر بخش عمومی (مقالات، دسته‌بندی‌ها، نمونه‌کارها)، یه پنل مدیریت کامل برای مدیریت کاربران، مقالات و نظرات داره.

## تکنولوژی‌ها

- **Next.js** (App Router) — فریم‌ورک React
- **Tailwind CSS v4** — استایل‌دهی
- **React Icons** (`react-icons/ri`) — آیکون‌ها
- **Vazirmatn** — فونت فارسی (از CDN)
- **MongoDB + Mongoose** — دیتابیس (در حال توسعه)
- **JavaScript** (بدون TypeScript)
